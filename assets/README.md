# Icona Assistente IT

Icona originale del progetto: monitor bianco su fondo blu con terminale e spunta verde.

- `AssistenteIT.svg`: sorgente vettoriale modificabile.
- `AssistenteIT.ico`: icona Windows con trasparenza a 32 bit, nelle dimensioni 16, 20, 24, 32, 40, 48, 64, 128 e 256 pixel.

L'ICO è incluso nel launcher, nel setup, nel programma di disinstallazione e nei collegamenti; le finestre di Assistente IT e Computer Explorer usano lo stesso file. La build usa direttamente l'ICO versionato, senza richiedere strumenti di grafica sui PC dei colleghi o sul runner.
