# Assistente IT 1.0.3

Aggiunta un'icona dedicata: monitor bianco su fondo blu con spunta verde.

- Icona nelle finestre di Assistente IT, Impostazioni e Computer Explorer, inclusi i dialoghi del modulo.
- Icona incorporata nell'eseguibile, nel setup e nel programma di disinstallazione.
- Collegamenti nel menu Start e sul desktop con la stessa icona.
- Formato Windows a più risoluzioni, da 16 a 256 pixel, con trasparenza; sorgente vettoriale incluso nel repository.

Chiudere il programma ed eseguire **Assistente-IT-Setup-1.0.3.exe**. L'aggiornamento conserva configurazione e token personali.
