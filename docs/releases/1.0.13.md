# Assistente IT 1.0.13

- Backup verificato delle chiavi BitLocker prima dell'eliminazione da AD, Intune o Entra ID. Un errore nel backup blocca il computer.
- Usa le **Note native** della scheda computer GLPI 10.0.11, senza plugin e senza nuovi campi nel database. Le password di recupero sono leggibili in chiaro in GLPI.
- **Aggiunge nuove note** senza modificare, cancellare o riscrivere quelle gia presenti. Le chiavi precedenti vengono conservate; una chiave identica gia archiviata dall'app viene verificata e riutilizzata. Una discordanza blocca l'operazione senza sovrascritture.
- Nuovi pulsanti **Archivia BitLocker** (senza cancellare) e **Leggi archivio**. Nessuna password di archivio da configurare.
- Anteprima con scheda GLPI, seriale, Key ID, volume e origine. Seriale discordante, schede GLPI ambigue o assenti bloccano l'operazione. Per associazioni basate sul nome occorre conferma esplicita.
- Le chiavi Entra richiedono **BitlockerKey.Read.All**, un ruolo adeguato e l'eventuale consenso amministrativo. Il profilo GLPI deve poter leggere e aggiornare le Note dei computer interessati.

Chiudere Computer Explorer e aggiornare dalla schermata principale. Provare prima **Archivia BitLocker** e controllare le Note GLPI, poi usare l'eliminazione.
