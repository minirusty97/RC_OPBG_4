# Assistente IT 1.0.10

- Ripristina il login interattivo Microsoft/WAM del vecchio script, senza forzare il codice dispositivo. Un riferimento a una finestra Windows valido permette al broker di mostrare l’accesso anche quando la suite è avviata senza console.
- Usa ContextScope CurrentUser: il modulo Microsoft conserva la sessione nella propria cache protetta per l’utente Windows. Il login può essere riutilizzato tra processi e riavvii dell’app, nel rispetto dei criteri del tenant.
- Mantiene l’app Microsoft Graph predefinita e i permessi Entra/Intune esistenti. Il consenso amministrativo non viene concesso o modificato dall’app.
- La finestra di attesa compare prima della chiamata di autenticazione. Se il modulo Microsoft passa al codice dispositivo, le istruzioni sono raccolte anche dalla console nascosta e dai flussi di informazioni/avvisi.
- Gli errori di autenticazione sono mostrati esplicitamente. Annullamento e conclusione ripristinano le finestre e l’output anche durante le operazioni di rimozione.

Aggiornabile dalla versione 1.0.8 e successive tramite Aggiornamenti → Aggiorna.
