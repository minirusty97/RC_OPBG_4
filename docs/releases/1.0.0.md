# OPBG IT Suite 1.0.0

Prima versione installabile della suite, con **Computer Explorer** come primo modulo.

- Ricerca per frammento sui cinque DC, Entra ID, Intune e GLPI, con interrogazioni parallele.
- Presenze, date di modifica/attività/check-in/inventario, percorsi AD e dettagli degli oggetti.
- Selezione multipla e rimozione da AD, Entra e Intune dopo verifica e anteprima. GLPI resta in consultazione.
- Finestra iniziale della suite e Impostazioni per DC, URL e token GLPI.
- Installazione per utente con collegamenti nel menu Start e sul desktop; modulo Microsoft.Graph.Authentication incluso.
- Configurazione e token personali separati dal programma e conservati durante aggiornamento e disinstallazione.

Scaricare **OPBG-IT-Suite-Setup-1.0.0.exe** dagli asset ed eseguirlo. RSAT/ActiveDirectory è richiesto per usare AD; ogni collega deve avere i propri accessi e permessi. Il setup è a 64 bit e non è firmato con un certificato di code signing. Il file SHA256 permette di verificarne l'integrità.

Al primo avvio aprire **Impostazioni** e configurare GLPI. Chi usa già la versione da sorgenti può copiare il proprio JSON e `.env` in `%LOCALAPPDATA%\OPBG\ITSuite\Config` dopo il primo avvio, con i moduli chiusi.

Validazione automatica su Windows PowerShell 5.1: suite di test con API simulate, compilazione, installazione pulita, avvio della finestra installata, aggiornamento, conservazione dei file personali e disinstallazione. Il workflow non usa credenziali aziendali e non esegue cancellazioni reali.
