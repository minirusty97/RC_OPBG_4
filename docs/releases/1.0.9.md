# Assistente IT 1.0.9

- Nella schermata principale Microsoft Graph e Active Directory (RSAT) hanno ciascuno una riga di stato, sempre visibile: verde se disponibile, arancione se il componente manca.
- I messaggi di aggiornamento e le notifiche occupano una riga separata e non sostituiscono lo stato dei componenti.
- Aumentata l’altezza della finestra per mantenere leggibili i nuovi stati.

La versione 1.0.8 può installare questa release dal pulsante Aggiorna.
