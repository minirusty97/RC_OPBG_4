# Assistente IT 1.0.8

- Controllo aggiornamenti in background all’avvio e pulsante Aggiornamenti nella finestra principale. Usa le release pubbliche di minirusty97/RC_OPBG_4, senza token GitHub sui PC.
- Aggiorna mostra versione e note, scarica il setup e ne verifica dimensione e SHA256. I download e i redirect devono usare HTTPS su host GitHub consentiti, con limiti di dimensione e timeout.
- Installazione richiesta dall’utente: chiusura della finestra, attesa dei moduli e del launcher, nuova verifica del file e avvio del setup per utente. Le operazioni in corso non vengono terminate. Configurazione e credenziali DPAPI rimangono nella cartella personale.
- Login Graph con codice Microsoft: le istruzioni arrivano subito all’interfaccia, il browser predefinito viene aperto e il codice è visibile e copiabile. Funziona anche dal processo nascosto della suite; una sessione Graph già valida viene riutilizzata.
- Il flusso di accesso non concede permessi né aggira le approvazioni del tenant. Eventuali criteri che vietano l’accesso con codice devono essere gestiti dagli amministratori.

Installare manualmente questa versione per attivare il controllo OTA delle successive release. Finché la repository è privata, il controllo anonimo segnala che la release non è raggiungibile; renderla pubblica abilita i download senza credenziali.
