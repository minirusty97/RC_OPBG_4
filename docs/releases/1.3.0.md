# Assistente IT 1.3.0

- **Stato accesso** nel wrapper con account Microsoft e risultato delle
  letture. Dopo il primo Accesso confermato la sessione viene verificata
  automaticamente all'apertura tramite la cache protetta del profilo Windows.
- La verifica iniziale esegue solo letture Entra, Intune e gruppi. I servizi
  valutano i diritti per BitLocker e per le scritture durante le operazioni.
- **Verifica Hybrid Join** e **Gestione Ring** consultano le schede GLPI in
  tutte le entità autorizzate al profilo API, comprese quelle esterne
  all'entità predefinita.
