# Assistente IT 1.0.18

- Accesso e verifica delle autorizzazioni nel wrapper iniziale, prima dell'apertura del modulo, con riepilogo delle funzioni disponibili e di quelle prive di consenso.
- Le funzioni di ricerca, BitLocker ed eliminazione controllano soltanto la sessione predisposta: non avviano login o richieste aggiuntive di permessi durante l'uso.
- L'app dedicata legge i consensi gia concessi tramite .default. Un consenso mancante, compreso Directory.AccessAsUser.All, viene segnalato all'inizio senza bloccare le altre funzioni disponibili e senza passare automaticamente a un'altra app.
- Conservato l'accesso tramite app Microsoft e il supporto alla cancellazione Entra quando ambito e diritti sono disponibili. Il backup BitLocker verificato nelle Note GLPI continua a precedere ogni cancellazione.
- Requisiti Graph dichiarati per modulo nel manifest, pronti per i moduli futuri. Accesso e modulo condividono il contesto SDK nello stesso processo senza file di passaggio dei token.
- Rimosse la modalita applicativa con certificato e le relative impostazioni. Gli accessi utente gia configurati restano disponibili.

La verifica iniziale usa solo letture limitate su Entra e Intune; non prova eliminazioni e non legge password BitLocker. Gli ambiti presenti non sostituiscono i ruoli dell'utente. Dettagli in docs/Accesso-Iniziale.md.
