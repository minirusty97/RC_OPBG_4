# Assistente IT 1.0.5

- Altezza delle righe dei risultati bloccata, senza cambiare la selezione multipla.
- Ctrl+C copia le righe selezionate con intestazioni. Il menu destro consente di copiare la singola cella o le righe selezionate.
- Colonna Censito: spunta verde solo quando tutte le schede GLPI dello stesso nome hanno il Gruppo assegnatario CENSITO, leggibile e senza conflitti di seriale. Non viene usato il gruppo tecnico. Nessun gruppo viene modificato.
- Colonne Seriale Intune, Seriale GLPI e Verifica seriale: seriali diversi, anche nella stessa fonte, sono segnalati come conflitto. I valori mancanti o segnaposto non confermano una corrispondenza.
- I conteggi restano un raggruppamento per nome, non una prova di identità hardware. AD ed Entra non espongono qui un seriale confrontabile. Nessun ID viene associato o scartato automaticamente; le selezioni con conflitti di seriale non possono essere eliminate dall’interfaccia.
- Test isolati per gruppi GLPI, seriali, clipboard, selezione e blocco delle eliminazioni ambigue.

Chiudere il programma prima di installare **Assistente-IT-Setup-1.0.5.exe**. Configurazione e token personali vengono conservati.
