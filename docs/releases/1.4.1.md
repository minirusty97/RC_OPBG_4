# Assistente IT 1.4.1

- **Elimina** in Computer Explorer agisce solo sulle origini confermate per ogni riga e sugli oggetti già mostrati. Se compare un nuovo ID, quella riga richiede una nuova ricerca.
- Il wrapper usa angoli smussati per schede, pannelli e pulsanti. I comandi disabilitati hanno uno stile più riconoscibile. **Accesso** usa lo stesso colore degli altri comandi ordinari.
- **GLPI** è ora nel pannello **Stato accesso**, con l'utente della sessione API quando configurato.
