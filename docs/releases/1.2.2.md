# Assistente IT 1.2.2

- Corrette le false assenze GLPI causate dall'ordine dei criteri nelle
  ricerche raggruppate per seriale Intune o per nome esatto. La correzione
  si applica a Gestione Ring e Verifica Hybrid Join.
- Il pulsante **Apri scheda GLPI** apre la scheda associata alla riga
  selezionata. Gli errori di apertura vengono mostrati nella barra di stato.
