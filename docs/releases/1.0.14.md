# Assistente IT 1.0.14

- **Cerca chiavi** legge prima da Intune, tramite azureADDeviceId e API BitLocker cloud, poi cerca in AD se necessario. Funziona con il nome esatto anche senza risultati nella griglia, senza inventario Entra o credenziali GLPI. Mostra chiavi copiabili ed esiti separati delle fonti.
- Il backup legge le password cloud prima di AD e accetta anche le risposte Graph contenute in value; prima delle eliminazioni resta obbligatoria la verifica completa delle origini selezionate. Le Note GLPI gia presenti restano inalterate.
- Limite di attesa per le letture Entra e Intune nella ricerca: 90 secondi per fonte, configurabili con Search.CloudReadTimeoutSeconds (1–600). Le configurazioni esistenti ereditano il valore predefinito.
- Il footer mostra pagina in lettura e record gia letti, anche se il nome cercato non esiste piu.
- Una lettura oltre il limite viene arrestata e segnalata come errore; una fonte non verificabile non viene mostrata come dispositivo assente. Le altre fonti conservano i propri risultati e la cache della fonte scaduta viene invalidata.
- Le ricerche concluse correttamente senza corrispondenze mostrano Nessun dispositivo trovato e consentono subito un'altra ricerca.
- Prove automatiche per nomi assenti, raccolte Graph vuote, aggiornamenti di avanzamento, timeout e riuso del coordinatore dopo l'arresto, con GUI nativa Windows.

Chiudere Computer Explorer e aggiornare dalla schermata principale. Riprovare il nome interessato con Rileggi cloud; se Entra non risponde entro il limite, il dettaglio della fonte riporta l'errore.
