# Assistente IT 1.4.0

- Computer Explorer interroga fino a cinque DC in parallelo con lettori isolati. I DC in errore hanno un ritentativo in sequenza. **Apri log** mostra fasi, tempi ed esiti di ogni ricerca.
- Il wrapper verifica automaticamente la sessione Microsoft salvata. Se serve un intervento, **Accesso richiesto** appare in rosso e i moduli attendono la conferma dal pulsante **Accesso**.
- Il pannello compatto raggruppa stato accesso e componenti con indicatori colorati. Mostra l'utente della sessione API GLPI e distingue la raggiungibilità di GitHub dallo stato dell'aggiornamento.
- Le schede dei moduli sono più compatte e mostrano la modalità di accesso accanto al pulsante **Apri modulo**.
